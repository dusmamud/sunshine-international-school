# Sunshine International School

Demo school website — Svelte 5 + SvelteKit 3 + Tailwind CSS v4 + adapter-static (prerendered).

**All content is demo/mock data** (names, fees in ₹, dates, testimonials, photos) for client
presentation, matching the reference design (maroon #7A1E2B, gold #C9A227). Replace with real
school data before a real launch. Live URL (once deployed): https://sunshine-international-school.pages.dev/

## Develop
```sh
npm ci
npm run check   # svelte-check
npm run build   # outputs build/
npm run preview # restart preview after every rebuild before screenshotting
```
